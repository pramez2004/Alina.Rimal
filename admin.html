How this works — this site has no server, so changes here save only in this browser (as a draft) until you publish them.
  1. Edit anything below — it auto-saves as a draft in this browser as you type.
  2. Click Download Updated Files at the bottom — you'll get two files: site-data.js and works-data.js.
  3. In your project folder, replace the existing js/site-data.js and js/works-data.js with the downloaded versions.
  4. Upload/commit those two files to your GitHub repo the same way you've been uploading everything else — the live site updates from there.
